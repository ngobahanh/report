# Hệ thống Tổng hợp Báo cáo - Project Root

Dự án hệ thống quản lý báo cáo nội bộ cho đơn vị quân sự.

## 📁 Cấu trúc

```
reportsystem/
├── backend/          - Express API server
├── frontend/         - React + Vite app
├── database/         - MySQL scripts
├── docs/            - Documentation
└── QUICK_START.*    - Setup scripts
```

## 🚀 Quick Start

### Windows
```batch
QUICK_START.bat
```

### macOS/Linux
```bash
bash QUICK_START.sh
```
